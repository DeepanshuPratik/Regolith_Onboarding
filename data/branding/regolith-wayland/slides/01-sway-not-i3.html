sway, not i3 — same keys, sharper picture

Regolith on Wayland runs the same configuration style as Regolith on i3, but sway is its window manager instead. Every binding you may have learned is unchanged: the same mod, the same direction keys, the same window-swallowing and scratchpad. The config lives at ~/.config/regolith3/sway/config in the same shape it always did.

  • Super + EnterA terminal. Foot, if Regolith installed it.
  • Super + SpaceAnything else. Rofi, with the same fuzzy search.
  • Super + 1…9Jump to a workspace. Named in the config, ordered by your preference.
  • Super + Shift + QReload the config. No need to log out while you tune it.

If a binding does nothing, it has been removed from the upstream config — not broken on your end.
