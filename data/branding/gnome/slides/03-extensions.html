When the desktop should grow

GNOME ships with the essentials and nothing else, on purpose. The things you miss are one install away: a dock that hides, a clipboard that remembers, indicators for what your apps are doing. Extensions sit on top of the shell rather than changing it, so removing one returns the desktop you had before.

  • https://extensions.gnome.orgBrowse from the browser. A button on the page installs the extension when you click it.
  • Extensions appToggle, configure, remove. Also reaches settings the web page doesn't expose.
  • gnome-extensions listFrom a terminal. Useful when an extension goes wrong and the GUI is the thing that broke.

Start with two: a clipboard manager and a system-monitor in the top bar. The rest you'll know you want.
