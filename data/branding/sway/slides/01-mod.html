$mod is the only modifier you need

sway's whole keymap is built on one variable. Whatever key you bind to $mod in your config is the prefix for every shortcut on this page — by default the Super key, but the Sway installation guide recommends the Caps-Lock key for users who type a lot, since Super is closer to the home row.

  • Edit ~/.config/sway/configChange $mod. One line, one Mod4 instead of another. Log out and back in.
  • man 5 swayThe reference. Every option, with examples, is one terminal away.
  • swaymsg reloadApply a config change. No logout; useful while iterating on bindings.
  • swaymsg -t get_configSee what sway is actually using. The shipped defaults plus yours, concatenated, in one dump.

If a binding does nothing, check whether $mod in your config is what your finger is pressing.
